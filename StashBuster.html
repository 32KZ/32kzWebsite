StashBuster

  • Minecraft
  • Paper plugin
  • Private

StashBuster is a dupe mitigation plugin for Minecraft 1.21.1 servers. If a dupe gets out and everyone ends up maxed, install it and it will quietly log where tracked items are being stored.

When you're ready, it sends a plain-English report of every stash to a webhook, so admins can clean up.

What it does

  • Tracks storage containers that hold the items you choose to watch.
  • Webhook reports with selectable dump modes.
  • Watch mode to follow a player's actions in real time.
  • An in-game admin interface (/stashbuster), exemptions and fine-grained permissions.
