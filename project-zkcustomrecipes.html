ZKCustomRecipes

Server-side custom crafting recipes for Minecraft, set up from a config file.

Status
Private repository
Language
Java
Started
2026

ZKCustomRecipes lets a server define its own crafting recipes in a config file, including enchanted results, without any client mods.

This project is private, so the code isn't publicly available.

All projects

Highlights

  • Recipes defined in config, with enchantment support
  • /recipes lists recipes, shows one in detail or reloads the config
  • Per-recipe crafting permissions
