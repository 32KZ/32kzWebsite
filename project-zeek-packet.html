ZEEK Packet

A private add-on for the Meteor Minecraft client with packet and utility modules.

Status
Private repository
Language

Started

ZEEK Packet is a private add-on for the Meteor client on Minecraft 1.21.11. It's designed to be verbose and easy to use, with clear chat feedback from every module.

This project is private, so the code isn't publicly available.

All projects

Highlights

  • Basic and advanced packet delay with chat notifications
  • Latency testing module
  • A port of UI-Utils for 1.21.11
  • A panic toggle that disables and hides modules in one press
