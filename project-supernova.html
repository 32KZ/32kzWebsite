SUPERNOVA

A standalone command-centre desktop app for Windows, built around workspaces of live widgets.

Status
Private repository
Language
TypeScript
Started
2026

SUPERNOVA is a desktop command centre for Windows. Each workspace is a set of managed native windows, so files, a terminal, code, an assistant, system monitors and more sit side by side and remember their layout.

Workspaces keep their layouts, project folders and widget state while you hide or switch between them, and an overview window shows every workspace laid out across your real monitor arrangement.

This project is private, so the code isn't publicly available.

All projects

Highlights

  • Widgets for Files, Terminal, Code, Assistant, Tasks, Launcher, Dev Log, CPU, GPU, System, Global Situation and Clock
  • Workspace overview that mirrors your physical monitors, with drag and drop to move or swap widgets
  • A radial widget dial for adding widgets, plus configurable shortcuts and a global summon key
  • Command-line launcher and a Windows installer build
