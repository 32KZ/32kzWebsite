ZEEK

  • Minecraft
  • Spigot plugin
  • Private

ZEEK is the plugin I wrote for my own Minecraft server. It adds small features I felt should already be in vanilla, and lets operators control a few game rules without editing files.

Private repository All projects
Language
Java
Built with
Maven, Spigot API
Minecraft
1.20 to 1.21.1
Active
Nov 2024 to Apr 2025

What it does

  • /zcosmetic adds particle effects to a player, with a pattern and particle count.
  • /ZControl toggles game rules such as TNT block damage, which is off by default.
